## Data-source decision

The retired `fundgz.1234567.com.cn` endpoint is not used. The live adapter targets the current TianTian Fund H5 `FundValuationLast` endpoint and its Eastmoney fallback, with batched `FCODES` requests. Providers returning null intraday estimates are surfaced as unavailable rather than converted to fabricated values.

## Important packaging note

The uploaded `fund_watch.zip` reviewed on 2026-09-01 did not contain the claimed `init_pg.sql`, verification scripts, or complete 12-table PostgreSQL delivery. It contained an older backend tree and a `backend/.env`. That `.env` was not copied to GitHub. The missing verification/schema artifacts were recreated directly in this repository and are the source of truth.

## Test status

Static verification is designed to run without a database. E2E verification requires a real PostgreSQL connection via `DATABASE_URL`; it is intentionally reported as pending when no database is configured.
